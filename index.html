1. Introduction

Bsun Image Resizer is a Windows desktop application developed by Bisan Subba. It allows users to resize images, adjust image dimensions, preview resizing results, and save images in supported formats.

This Privacy Policy explains how the application handles user information and image files.

2. Information Collection

Bsun Image Resizer does not collect, transmit, or share personal information.

The application does not require registration, user accounts, or personal details.

3. Image Processing and Storage

All image processing takes place locally on the user's Windows computer.

  • Images are not uploaded to external servers.
  • Images are not transmitted to the developer.
  • Users choose which images to process.
  • Resized images are saved to user-selected locations.
  • No online image database is maintained.

4. Internet Connectivity

Bsun Image Resizer does not require an internet connection for its image resizing functionality. Processing is performed locally on the device.

5. Third-Party Services

Bsun Image Resizer does not integrate advertising networks, analytics services, or third-party tracking systems.

The application is developed using Python, Tkinter, and Pillow for its graphical interface and image processing functionality.

6. Data Sharing

The developer does not receive, sell, or share users' images or personal information through the application.

7. Data Security

Images are processed locally, allowing users to retain control over their files and selected save locations.

Users are responsible for managing and protecting files stored on their computers.

8. Children's Privacy

Bsun Image Resizer does not knowingly collect personal information from children or adults.

This Privacy Policy may be updated when application features or data-handling practices change.

Any updates will be published on this page with a revised date.
